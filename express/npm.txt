package.json <- 프로젝트 관련정보(이름,버전,설명,의존성,실행 스크립트)
package-lock.json <- 의존성 버전과 정보에 대한 상세 내용과 버전 고정용(버전끼리 충돌 생기지 않게끔 버전을 잠궈놓음)

// [] 괄호안에는 언제든 바뀔수 있다는걸 의미
npm install [package] <- 최신버전을 의미
npm install [package] @~1.13.0     <- 1.13.x 버전을 의미 (x는 최신 버전 반영)
npm install [package] @^1.13.0     <- 1.x.x 맨 앞 정규 버전만 지키고 맘대로 반영해라
npm install [package] @1.13.0      <- 1.13.0 버전을 의미

npm install -D [package]           devDependencies   // -(하나) 약자 --(두개) 풀네임
npm install --save-dev [package]   devDependencies 

npm install --production           <- dependencies   것만 설치
npm install --production [package]           <- 특정한 package 를 dependencies에 설치
npm install --global [package]     <- 모든 프로젝트에서 사용하도록 설치
npm install -g [package]

//설치한 파일을 지우고 싶을때
npm remove [package]               <- package 삭제
npm run [script-name]              <- npm run dev 같은 것

npx : npm 으로 패키지 설치 없이 사용하게 해주는 도구
npm install [package]              <- 설치 시 node_modules에 다운로드되어 저장
npx install [package]              <- 설치 시 사용 후 삭제, 1회성 라이브러리에 사용
